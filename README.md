# e-test.ro

Platformă gratuită de testare online, cu acces la teste pentru utilizatori autentificați.

## Stack

- Laravel 13
- Livewire 4
- Blade
- Tailwind CSS 4
- Alpine.js
- PostgreSQL
- Redis
- Pest
- Vite

## Principii de produs

- cont obligatoriu pentru susținerea testelor;
- testele rămân gratuite;
- URL-uri fără prefix redundant `/teste/`;
- arhitectură pregătită pentru verticale multiple, white-label și API;
- deployment pe VPS;
- mobile-first, SEO-first și i18n-ready.
